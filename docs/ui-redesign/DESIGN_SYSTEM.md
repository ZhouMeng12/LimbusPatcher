# 巴士 · 三主题界面设计系统规范

> 适用产品：**边狱巴士汉化文本修改器**（PySide6 桌面端）
> 版本：v3 ｜ 对应程序版本 v0.9.3
> 设计目标：**美观且易用** —— 以第一版 AURUM 暗金为**默认**风格，另备「巴士（原版配色）」与「简约·亮」两套可选主题，并把信息层级、可读性、操作路径三件事一次性理顺。

---

## 0.1 v2 改版（本轮）：三主题 + 单颗状态药丸 + 导航重排

v1 交付了 AURUM 暗金设计系统（诊断 → token → 组件 → 落地）。v2 在此基础上按用户决策做了五处调整（D5 是后续修正）：

| # | 决策 | 落地 |
|---|---|---|
| **D1** | **顶栏收敛成单颗状态药丸** | 原先并排 5 颗 chip（保存/环境/应用/待确认/补译）等价无主次 → 收敛成 **1 颗**药丸，默认只显示**最需要注意的那一条**（`err > warn > info > ok > none`，同级取靠前），点击弹出完整清单（`StatusPill` / `StatusPopover`）。 |
| **D2** | **亮色主题正式做进去** | 不再是"顺带一提"的变体：`mini-light` 与 `mini-dark` 平级，可持久化（`config.json` 的 `ui.theme`），并用对比度测试卡住。 |
| **D3** | **按原版架构与配色重做主风格** | 新增 `bus` 主题：纯黑底 + 原版品牌金 `#F1BF02`（Corn）/ `#B48600`（Pirate Gold）+ **直角细金边**（圆角一律 0）。 |
| **D4** | **保留 AURUM 为一个风格** | 原暗金 = `mini-dark`，加亮色 = `mini-light`。切换器是 **`1 + (1+1)`**：左侧「巴士」直接选，右侧「简约 ▾」点开才分「暗 / 亮」。 |
| **D5** | **默认主题回到第一版**（后续修正） | `bus` 是**纯黑底 + 近白字**（`#0b0b0d` / `#eae7e0`），整体观感偏"黑白"；亮色又是白底，来回切很像在黑白之间跳。用户明确要第一版那套**暖调暗金**，因此 **`DEFAULT_THEME` 改为 `mini-dark`**，`bus` 与 `mini-light` 降为**可选**风格（切换器里仍能选到，不再默认）。 |

**信息架构同步重排**（决策 B1「连信息架构一起重排」）：

1. **导航顶部独立「工作台」**：全部文本 / 最近修改 / 待确认 / 我的收藏 / 补译文本 —— 跨分区的任务入口集中一处。
2. **按游戏原版分区重排**：剧院 / 镜牢 / 人格 / E.G.O / RPG 剧情 / 关卡与敌人 / 系统与设置。
3. **补齐可达性（本轮最大的实际收益）**：改版前导航只露出 人格图鉴 / 敌方图鉴 / 剧本模式 与「系统与界面」五项，**人格、E.G.O、技能、战斗效果、镜牢、异想体、主线剧情等 20 类在导航里点不到**，只能去列表顶部的分类下拉里翻。改版后 `NAV_ZONES` 的叶子**恰好覆盖全部 27 个分类**（守卫见 `tests/test_nav_zones.py`）。
4. **去掉等价重复入口**：人格图鉴 / 敌方图鉴 移出导航，由顶栏**整页 tab** 独占入口（一屏内不再有两个入口通向同一页面）。

> 主题切换后**重建界面**（而非就地刷新控件），因为除颜色外形状/描边也随主题变，且菜单、快捷键、图鉴页都持有具体控件引用；重建窗口是唯一能保证不留悬空引用与陈旧样式的做法。会话状态（几何/分栏/分类/搜索/条目/剧本位置）在切换前落盘、新窗口自动还原。

### 形状 token 的两处修正

* **`RADIUS_PILL` 三主题统一为 999（完全圆头）**。原型里 `--radius-pill:999px` 对
  **所有**主题成立，所以「巴士 = 直角」只作用于**容器 / 按钮 / 行**，药丸仍是圆的。
  落地前 `bus` / `mini-*` 分别是 0 / 10。
* 新增 `LOGO_CUT`（原型 `--cut`）：`bus` = 10px、`mini-*` = 0。品牌 logo 的斜切角用
  `QPainterPath` 画，`border-radius` 画不出"直角上的斜切口"。

### 这一轮又抓到 3 个**早已存在**的豆腐块

`scripts/scan_glyphs.py` 会把 `ui/*.py` 里每个「当符号用」的字符**真的渲染成图并数像素**，
像素数与豆腐块一致即判定缺字形。它一次找出 5 个，其中 3 个是本轮之前就有的：

| 码位 | 符号 | 位置 | 处理 |
|---|---|---|---|
| U+21B6 | 逆时针弯箭头 | `editor_panel.py` 撤销按钮 | 去掉箭头，只留「撤销」 |
| U+21B7 | 顺时针弯箭头 | `editor_panel.py` 重做按钮 | 去掉箭头，只留「重做」 |
| U+25B8 | 小实心右三角 | `enemy_codex_page.py`「按关卡查询敌人」 | 换 `▼`（它其实是菜单按钮） |
| U+27F5 | 长左箭头 | `script_panel.py`「切回条目模式」 | 换 `←` |
| U+22EF | 居中省略号 | 本轮新增的「更多操作」按钮 | 三颗点**自绘**（`MoreButton`） |

全部 21 个界面符号的实测结果见 `.workbuddy/scan_glyphs.log`；
`tests/test_ui_glyphs.py` 的 `FORBIDDEN` 名单已同步扩到 15 个码位。

> **注意**：`…`(U+2026) 有字形但贴在基线上、视觉偏低；`•••` 三颗点自绘最稳，
> 这也是 `MoreButton` 不用文字的原因。

## 0. 为什么改：现状诊断

改版不是重画一遍，是针对实测出来的问题开药。以下每条都有依据。

| # | 问题 | 依据 | 影响 |
|---|---|---|---|
| P1 | **错误状态看不清** | `ERROR #b45f4d` 在背景 `#121417` 上对比度仅 **4.12**，在面板 `#1b1f24` 上仅 **3.69** —— 均未达 WCAG AA 正文 4.5 | 「环境异常 / 未选目录 / 缺失」这些最要紧的状态反而最难读 |
| P2 | **顶栏过载，无视觉落点** | 一行内塞了 方案名 + 5 颗状态 chip + 3 个按钮 + 操作菜单，共 10+ 元素 | 不知道先看哪；状态与操作混在一起 |
| P3 | **强调色被稀释** | `ACCENT #c8a24a` 同时用于：选中态、chip 边框、进度条、按钮 hover、菜单选中 | 金色不再等于「重要」，语义失效 |
| P4 | **编辑器主次倒挂** | 「零协原文 / 英语原文 / 自定义文本」三栏 `setSizes([300,300,300])` 等宽 | 主任务（写自定义文本）与两个只读参考栏平权，焦点错位 |
| P5 | **按钮无层级** | 编辑区一行平铺 9 个按钮（撤销/重做/保存/还原/历史/剧本/收藏/差异/英语原文），仅「保存」是 primary | 高频与低频操作混排，误点成本高 |
| P6 | **筛选器过载** | 范围 / 实体 / 内容 / 章节 / 关卡 / 赛季 / 种类 + 分组 + 状态，全是一排下拉 | 新用户不知道从哪下手 |
| P7 | **缺乏状态设计** | 列表与编辑器只有文字空态，无加载态、无骨架屏、无操作反馈 | 索引重建（19 万条）期间体验空洞 |

**改版后必须成立的三条验收线**：① 全部文字与状态色达 WCAG AA；② 顶栏一眼能分出「状态区 / 操作区」；③ 编辑主任务在不滚动的情况下占据最大注意力。

## 1. 设计原则

1. **金色是意志，不是装饰。** 暗金只用于三处：主行动、当前选中、进度。其余一律灰阶。让「有颜色 = 有含义」重新成立。
2. **四层表面造深度，不用阴影堆。** 桌面应用靠明度层次（背景 → 面板 → 卡片 → 浮层）建立秩序，比投影更克制、更耐看。
3. **内容优先，工具退后。** 编辑区永远比工具栏重要；参考信息默认收起，需要时才占地方。
4. **每一步都可逆。** 危险操作给确认，普通操作给撤销，状态变化给反馈（toast / 药丸）。

## 3. 字体系统

沿用系统字体（中文桌面环境无需外部字体，也避免打包体积）：`Microsoft YaHei UI` → `Microsoft YaHei` → `Segoe UI` → `sans-serif`。

| Token | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| `display` | 22 / 30 | 700 | 空态标题、图鉴角色名 |
| `title` | 17 / 24 | 600 | 面板标题、条目名 |
| `subtitle` | 15 / 22 | 600 | 分区小标题 |
| `body` | 13 / 20 | 400 | **界面正文默认** |
| `body-strong` | 13 / 20 | 600 | 强调正文、按钮 |
| `caption` | 12 / 18 | 400 | 元信息、字数、徽标 |
| `mono` | 13 / 20 | 400 | ID、占位符、diff 内容（`Consolas, "Cascadia Mono", monospace`） |

**规则**：正文最小 13px（原设计即 13px，保留——桌面工具信息密度优先）；行高 = 字号的 1.45~1.55 倍；一段文字最多用两级字号。

## 4. 间距 / 圆角 / 描边 / 阴影 / 动效

### 间距（4pt 基准）

| Token | 值 | 典型用法 |
|---|---|---|
| `space-1` | 4 | 图标与文字间隙 |
| `space-2` | 8 | 同组元素间 |
| `space-3` | 12 | 面板内边距、紧凑行距 |
| `space-4` | 16 | 面板内边距（默认） |
| `space-5` | 20 | 区块之间 |
| `space-6` | 24 | 大区块分隔 |
| `space-8` | 32 | 空态上下留白 |

> 原设计里 `4 / 6 / 8 / 12 / 14` 混用（列表项 padding 4 与 6 并存），统一到 4 的倍数。

### 圆角

| Token | 值 | 用途 |
|---|---|---|
| `radius-sm` | 4 | 按钮、输入框、列表项 |
| `radius-md` | 6 | 卡片、面板 |
| `radius-lg` | 10 | 浮层、对话框 |
| `radius-full` | 999 | 药丸 / chip / 头像 |

### 描边与阴影

- 描边：默认 `1px solid border`；聚焦 `1px border-strong + 2px accent 外环`；**禁止用纯色块边界代替描边**。
- 阴影只给浮层（菜单/对话框/toast）：`0 8px 24px rgba(0,0,0,.45)`；面板与卡片**不用阴影**，用表面明度区分（原则 2）。

### 动效

| Token | 值 | 用途 |
|---|---|---|
| `dur-fast` | 120ms | hover / 颜色变化 |
| `dur-base` | 200ms | 展开收起 / 页面切换 |
| `dur-slow` | 320ms | 抽屉 / 对话框进出 |
| `ease` | `cubic-bezier(.2,.8,.3,1)` | 统一缓出 |

**必须**尊重 `prefers-reduced-motion`：降低动效时，位移与缩放归零，仅保留透明度变化。

   ↑ 三栏是独立卡片：8px 缝隙里透出更暗的窗口底色 BG（原型 .body{padding:8px;gap:8px}）

### 5.1 顶栏：整页入口归左可见、操作归右、主行动唯一

- **左**：品牌区（`[邊] 应用名 ●`，方案信息作副标题）+ 面包屑（`分区 › 条目`，分区名亮、分隔符最暗）
  + 竖分隔线 + **三颗整页入口 tab**（`QPushButton#pageTab`，可选中）。
- **右**：**单颗状态药丸** + `风格 · XX` + `应用到游戏`(primary，唯一) + `••• 更多操作`。

**整页入口为什么摆在顶栏可见处**（而不是收进 `•••`）：图鉴 / 剧本模式是「去哪」（导航语义），
跟面包屑同组；藏进菜单等于把最常用的三个页面各加一次点击。落地语义：

- 选中态 = 当前就在那一页（`_sync_page_tabs()` 以真实页面回写，唯一回写点）；
  再点一次 = 回工作台（tab 常规语义），同时面包屑回到当前分类。
- `•••` 里只放**工具类动作**：装零协汉化（英文底本时才显示）+ 原「操作」菜单项
  （清空 / 停用 / 备份 / 建议 / 补译 / 替换 / 基线 / 导入导出 / 目录 / 高级模式）。
- 面包屑跟随整页入口：进图鉴页显示 `图鉴 › 人格图鉴`，进剧本模式显示 `剧院 › 剧本模式`，
  与 tab 选中态由同一个 `_sync_page_tabs()` 驱动，不会出现「tab 亮着、面包屑还是旧分类」。

**为什么收敛成一颗药丸**（D1）：改版前 5 颗 chip 并排，每颗都带自己的颜色，用户每次都要把 5 条读完才知道"现在有没有问题"；实际使用中 90% 的时间其中 4 条是「已保存 / 环境正常 / 已应用 / 无待确认」这类"无话可说"的状态——**信息量低却占了最大注意力**。收敛后：

- 药丸文字 = **最需要注意的那一条**，按 `err(4) > warn(3) > info(2) > ok(1) > none(0)` 取最大值，同级取声明顺序靠前者（保存 → 环境 → 应用 → 补译 → 待确认）。
- 颜色跟着那条走（错误红 / 警告琥珀 / 提示蓝 / 正常绿 / 中性灰），**颜色终于等于"有含义"**：底与描边都取该语义色的低透明度版本。
- 点击 → `StatusPopover` 弹出完整 5 条清单（`label + value`，语义色），悬停药丸有 tooltip 汇总全部 5 条。
- `StatusPill` 用 `QFrame` 而非 `QPushButton`：需要在文字前放一个真正带颜色的圆点（按钮不支持富文本）。

### 5.2 导航：工作台置顶 + 按原版分区

```
工作台        ← 全部文本 / 最近修改 / 待确认 / 我的收藏 / 补译文本
剧院          ← 剧本模式 · 主线剧情 · 人格剧情 · 迷宫剧情 · 其他剧情 · 战斗剧情 · 间章与活动 · 折射轨道
镜牢          ← 镜牢 · 镜牢探索事件 · 饰品
人格          ← 人格 · 人格技能 · 人格语音 · 人格一览
E.G.O        ← E.G.O · E.G.O 技能 · E.G.O 语音 · E.G.O 一览
RPG 剧情      ← RPG 剧情 · RPG 对话 · RPG NPC · RPG 任务
关卡与敌人     ← 敌方单位 · 异想体 · 战斗对话 · 战斗效果 · 技能
系统与设置     ← 界面文本 · 系统提示 · 教程 · 道具与货币 · 罪人资料 · 其他
```

- **只展开「工作台」**，其余分区默认收起 —— 先让用户扫分区名，而不是先被 39 条挤满。`set_current()` 会自动展开选中项所在分区，避免"选中了却看不见"。
- **键值语义不变**：仍然只发 `category_selected(key)`，`key` 沿用既有分类 id / `role:*` / `entities:*` / 伪分类，所以 `_category_targets` / `_entity_context` 后端零改动。
- 分区结构定义在 `limbus_patcher/categories.py` 的 `NAV_WORKBENCH` / `NAV_ZONES`，与分类器用的 `CATEGORY_GROUPS`（`group_of()` 依赖）**分开**：一个管"怎么呈现"，一个管"怎么归类"。

### 5.3 其余三栏（v3 全量对齐原型）

- **三栏是独立卡片**：原型 `.body{padding:8px;gap:8px}` + `.pane{background:s1;border;radius}`。
  落地用 `QSplitter` 的 **8px 透明 handle** 当缝、工作区四周留 8px，
  缝隙里透出比面板更暗一层的窗口底色 `BG`。
  > 坑：缝隙颜色不能指望 `QMainWindow` 自己的背景 —— 离屏 `grab()` **不绘制顶层窗口背景**，
  > 缝会渲染成纯黑。必须在根容器上显式铺 `QWidget#appRoot{background:BG}`。
- **列表**：顶部一行 = 搜索框（占满）+ 「筛选」按钮（带已选数量角标）；常用筛选（状态 / 分组）直接外露，其余进抽屉；已选条件以 chip 回显，可单点清除。
- **编辑器** = 主列（自定义文本）+ 右侧**常驻参考栏**（原型 `.drawer open`）：页签 `零协原文 / 英语原文`，
  栏顶一行字段定位（`file / KeyID / idx / field`）。`Ctrl+E` 与工具条的「参考 Ctrl+E」在**两个页签间切换**。
  > 参考栏本轮做成**常驻**（原型初始就是 `.drawer open`），不提供折叠；留在原型的只有"哪一页在前"这个状态。
- **顶栏**（原型 `.topbar`，高 54）：左 = 品牌区（金 logo + 应用名 + 保存点，方案信息作副标题）+ 面包屑；右 = `状态药丸` / `风格 · XX` / `应用到游戏` / `•••`。

## 6. 组件规范

### 6.1 按钮

| 变体 | 样式 | 用途 |
|---|---|---|
| `primary` | 底 `accent`，字 `on-accent`，字重 600 | 每屏**最多一个**（应用到游戏 / 保存） |
| `secondary` | 底 `surface-2`，描边 `border`，字 `text` | 常规操作 |
| `ghost` | 透明底，hover 出 `surface-3` | 图标按钮、工具栏 |
| `danger` | 透明底 + `error` 描边与文字；hover 填充 `error` | 删除 / 清空 |

尺寸：`sm` 高 26（图标按钮 26×26）、`md` 高 30（默认）、`lg` 高 36。
状态：default / hover / pressed / focus-visible（2px accent 外环）/ disabled（`text-faint` + 不响应）。
**规则**：一行里 primary 不超一个；同类操作等宽等高；图标按钮必须带 tooltip 与 `aria-label`。

**带下拉的按钮**（`setMenu()`）不画原生菜单指示箭头 —— 「有下拉」统一由我们自己的
文案表达：`改名称 ▼` 用文字三角，顶栏 `•••` 用自绘三点（`MoreButton`）。
QSS 里显式钉死 `QPushButton::menu-indicator { image: none; width: 0; height: 0; }`。

> **实测结论（`scripts/probe_menu_indicator.py`）**：曾担心这类按钮会「文字三角 + Qt 箭头」
> 叠成两个箭头，**实测不存在** —— 裸 Fusion 下 Qt 确实会画（`PM_MenuButtonIndicator=12`），
> 但**只要套上本应用 QSS，`QStyleSheetStyle` 就不再画它**（有无上面那条规则都一样）。
> 保留该规则的目的是把意图钉死、并把该 metric 归 0，渲染上零差异。

### 6.2 输入框 / 下拉

`surface-2` 底、`border` 描边、`radius-sm`、内边距 `8×6`；聚焦时描边转 `accent` 并加 2px 外环。下拉与输入框同高同圆角。占位符用 `text-faint`。
**规则**：输入框必须带可见 label 或明确的 placeholder；错误态用 `error` 描边 + 下方 `caption` 说明，不能只靠变色。

### 6.3 列表项（搜索结果 / 剧情行）

- 高度 `compact 40` / `comfortable 52`（可在设置里切）；搜索结果行固定 44。
- 结构（原型 `.row`）：`[2px 状态色条] [标题 + 角色胶囊徽标] / [元信息 + 状态文字]`
  —— 上下内缩 5px 的竖条在**最左**，文字左内边距 11px（= 2px 条 + 9px 间隔）。
- 状态用**左侧 2px 竖条**表达（未修改 `STATUS_NONE` / 已修改 `accent` / 待确认 `warning` / 缺失 `error`，
  收藏恒为 `accent`），鼠标悬停底色 `surface-3`，选中 `accent-subtle` + 左条 `accent`。
- **角色胶囊徽标**（原型 `.row .t .rl`）：`surface-3` 底 + `border` 描边 + `radius-pill` + 10px 字，
  紧贴标题之后；标题按"总宽 − 徽标宽 − 6"省略，徽标永远不被挤掉。
  角色名**不再混进 meta 文字**（以前 `技能` 和 `章节 · 角色` 挤在一行分不出来）。
- **状态文字并入 meta 行**（原型 `.row .m` 的 ` · 已修改` 写法），不再单独右对齐一行。
- **分组标题行**：`subtitle` + 计数，不可选、不可点击。
- 状态色**按当前主题实时解析**（`list_panel.status_color()`）：模块级缓存会在换主题后留下旧主题的颜色。

### 6.4 状态药丸 / Chip / 徽标

- **状态药丸（顶栏唯一一颗）**：高 28，`radius-pill`；**底与描边跟语气同色系的半透明**
  （原型 `.pill.ok/.warn/.err`：底 `rgba(语义色,.12~.13)`、描边 `rgba(语义色,.32~.36)`），
  `.pill.mute`（正常 / 中性）才用 `surface-2` + `border`。内部 = `6px 圆点（语义色）` + `value`（`text`，600 字重） + `▼`（`text-faint`）。
- **状态总览面板（`#popover`）**：`surface-3` 底 + `border-accent` 描边 + `radius-md`；
  标题「当前状态」，随后若干行 `label(62px, dim) + 圆点 + value(语义色 600)`。
- **筛选 chip**：`surface-2` 底 + `border`，末尾带 `×` 可移除；激活态用 `accent-subtle` + `accent` 文字。
- **角色胶囊徽标**：`radius-pill`、10px 字、`surface-3` 底（见 6.3）。
- **计数徽标**：`radius-full`，`caption`，`surface-3` 底。

> 圆点形状不再随主题变方：`RADIUS_PILL` 三主题统一 999，所以圆点恒圆（见 0.2 的形状 token 修正）。

### 6.5 标签页 / 分段控件 / 风格切换器

- **标签页**：用于「零协原文 / 英语原文」参考切换。下划线式：激活项文字 `accent` + 底部 2px `accent` 条；其余 `text-dim`（`QPushButton#refTab`）。
- **风格切换器 `#themeBtn`**（v3）：顶栏**一颗**按钮，文案 `风格 · 巴士` / `风格 · 简约 · 暗`。
  点开 `#stylePop` 浮层（`surface-1` + `border-strong` + `radius-md`）：
  标题「界面风格」+ `236×40` 分段控件 `#switchTrack`（`surface-2` + `border` + `radius-pill`）。
- **分段控件**：选项为 `#segOpt`（透明底 + `text-dim`）；`:checked` 时底 `accent`、字 `on-accent`。
  `1 + (1+1)` 语义照旧：左半「巴士」直接选中；右半「简约」**点一下不提交**，
  而是把右半原地换成「亮 / 暗」两格，点亮暗才提交并重建界面。
  > 旧版把两格直接摆在顶栏上，和原型不符（原型顶栏只有一颗按钮），v3 已改回「单按钮 + 浮层」。

### 6.6 对话框

`radius-lg` + `surface-1` + 阴影；标题 `title`、正文 `body`、底部按钮右对齐（次要在左，primary 在右）；遮罩 `rgba(0,0,0,.5)`。
**危险确认**必须写明后果与对象数量（例：「将删除 **37** 条自定义文本，此操作不可撤销」），按钮文字用动词（「删除」而非「确定」）。

### 6.7 空状态

三要素：**图标/插画（accent 描边线性）** + **一句话说明现状** + **一个明确的下一步动作**。
例：列表空 → 「没有匹配的文本」+「试试清除 2 个筛选条件」；环境未就绪 → 引导走原有 Onboarding 页。

### 6.8 加载与骨架屏

索引重建（19 万条）必须给**确定性进度**：顶部细进度条（2px，`accent`）+ 列表骨架行（`surface-2` 占位块，1200ms 呼吸）+ 文案「正在建立索引 12,340 / 194,948」。
**禁止**只有转圈无进度。

### 6.9 反馈 Toast

右下角，`surface-3` + 阴影，`radius-md`，左侧 3px 语义色条；3 秒自动消失，可 hover 暂停。用于「已保存」「已应用到游戏（N 条）」「替换完成（37 处）」。**错误信息不用 toast 顶替**，需常驻可读。

## 7. 信息架构与核心流程

**主导航**：工作台（全部 / 最近 / 待确认 / 收藏 / 补译）+ 七个原版分区（剧院 / 镜牢 / 人格 / E.G.O / RPG 剧情 / 关卡与敌人 / 系统与设置）。图鉴页不在导航里 —— 顶栏按钮是它的独占入口。

**主题**：`1 + (1+1)` —— **简约·暗（默认，第一版 AURUM 暗金）** / 简约·亮 / 巴士（可选）。
选择写入 `data/config.json` 的 `ui.theme`，启动即生效。

**核心流程（3 步，每步都要有明确落点）**

1. **定位** —— 顶栏全局搜索 `Ctrl+K`，或左侧分区 + 列表搜索/筛选。任何一步都能看到「当前命中 N 条」。
2. **编辑** —— 点条目 → 编辑器主栏写自定义文本 → `Ctrl+S` 保存。原文/英文/差异都是**按需展开**的参考层，不打断主任务。
3. **应用** —— 顶栏主行动「应用到游戏」，状态药丸显示「已应用 / 待重新应用 / N 条待确认」。

**快捷键（保留并补齐）**：`Ctrl+S` 保存、`Ctrl+F` 搜索、`Ctrl+K` 命令面板（新）、`Ctrl+E` 参考栏页签切换（零协原文 ↔ 英语原文）、`Ctrl+Shift+D` 差异、`Ctrl+Z/Y` 撤销/重做、`Esc` 清空搜索。

## 8. 落地映射（→ `limbus_patcher/ui/theme.py`）

### 8.1 主题体系

```python
THEME_IDS    = ("bus", "mini-dark", "mini-light")
THEME_LABELS = {"bus": "巴士", "mini-dark": "简约·暗", "mini-light": "简约·亮"}
DEFAULT_THEME = "mini-dark"          # 第一版 AURUM 暗金（bus 是纯黑白观感，不做默认）
THEME_GROUPS = ({"id": "bus",  "label": "巴士", "children": ()},
                {"id": "mini", "label": "简约", "children": (("mini-dark","暗"),
                                                             ("mini-light","亮"))})
```

> `THEME_GROUPS` 的**顺序**只决定切换器里谁在左谁在右，与默认值无关；
> 默认值由 `DEFAULT_THEME` 决定。

- token 与几何量都通过模块级 `__getattr__`（PEP 562）**按当前主题动态解析**，所以 `theme.TEXT` / `theme.RADIUS_MD` 会跟随 `apply_theme()` 变化；10+ 处既有引用零改动。
- **几何分主题**：`_GEOMETRY_COMMON`（间距/字号/动效）+ `_GEOMETRY_BY_THEME`（圆角、描边宽、logo 斜切）。`bus` 的**容器/按钮/行**圆角为 0。
  - `RADIUS_PILL` 三主题统一 **999**（原型 `--radius-pill:999px` 对所有主题成立）。
  - `LOGO_CUT`（原型 `--cut`）：`bus` = 10、`mini-*` = 0。
- 新增模块：`ui/brand.py`（`LogoMark` / `SaveDot` / `MoreButton`）—— 品牌区与「更多操作」按钮。
- 旧主题名仍可用：`resolve_theme("dark") == "mini-dark"`、`"light" == "mini-light"`；非法值回落 `DEFAULT_THEME`。
- `apply_theme(app, mode)` 现在**返回实际生效的主题 id**，方便调用方与测试断言。
- 持久化：`AppConfig.ui.theme`（`config.py`），白名单校验；`main.py` 在建窗口**之前**读取并套用（控件构造时就要拿到正确颜色）。
